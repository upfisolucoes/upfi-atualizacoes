# Upfi ERP 1.1.0-beta.3 — Windows 7 SP1/8/8.1 de 32 ou 64 bits

Baixe em **Code → Download ZIP**, extraia o ZIP inteiro e abra **INSTALAR.cmd**.

Feche o programa antes de atualizar. Esta instalação preserva configurações e dados locais e ativa os avisos de novas versões. O SQL já aplicado no servidor não precisa ser repetido.

Depois desta instalação, as atualizações publicadas no canal principal serão anunciadas pelo programa. O usuário escolhe quando baixar e quando instalar/reiniciar. **Mais tarde** adia o lembrete por quatro horas.

O arquivo de preparação apenas junta as partes e confere SHA-256 antes de abrir o instalador. Leia `LEIA-ME.txt`. Versão de homologação, sem assinatura digital.
